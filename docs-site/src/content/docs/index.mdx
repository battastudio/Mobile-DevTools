## Four focused tools, one local dashboard

Mobile DevTools is a small platform that runs entirely on your machine. Clone it,
run `node serve`, and open the dashboard. Everything works on `localhost` against
your local Flutter toolchain and devices — nothing is uploaded anywhere, and there
is no login.

  <Card title="🚀 Build Helper" icon="rocket">

  <Card title="🧪 Mobile QA" icon="approve-check">

## Why zero-dependency?

Every tool uses only the Node.js standard library. There is no bundler, no
`node_modules`, and no build step. It stays fast to clone, trivial to audit, and
impossible to break with a bad transitive dependency.
